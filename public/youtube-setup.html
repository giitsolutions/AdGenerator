Connect YouTube to KwikPost

Separate from Instagram. Use these steps to allow uploads to your YouTube channel.

1

You need a YouTube channel

  • Sign in at youtube.com with the Google account you want to use
  • If you have no channel: your avatar → Create a channel
  • Prefer a Brand Account channel if a team will manage uploads
2

Create a Google Cloud project

  • Open Google Cloud Console
  • Select a project → New project → name it e.g. KwikPost
  • Open that project
3

Enable YouTube Data API

  • Menu → APIs & Services → Library
  • Search YouTube Data API v3 → Enable
4

Configure OAuth consent screen

  • APIs & Services → OAuth consent screen
  • User type: External (or Internal if Google Workspace only)
  • App name: KwikPost · support email: yours
  • Scopes → add https://www.googleapis.com/auth/youtube.upload and youtube.readonly
  • Test users: add your Gmail while the app is in Testing
In Testing mode only listed test users can connect. Publish the app later for all users.
5

Create OAuth client ID

  • APIs & Services → Credentials → Create credentials → OAuth client ID
  • Type: Web application
  • Authorized redirect URI (local):
    http://localhost:5000/api/youtube/callback
  • If you use a public HTTPS URL, add that callback too
  • Copy Client ID and Client secret
6

Add keys to KwikPost .env

YOUTUBE_CLIENT_ID=your_client_id.apps.googleusercontent.com YOUTUBE_CLIENT_SECRET=your_client_secret YOUTUBE_REDIRECT_URI=http://localhost:5000/api/youtube/callback APP_BASE_URL=http://localhost:5000

Restart the server after saving .env (npm start).

7

Connect your channel in the app

Instagram setup
You will see Google’s permission screen. Choose the account that owns the channel, then Allow.

Common problems

  • redirect_uri_mismatch — URI in Google Cloud must match YOUTUBE_REDIRECT_URI exactly.
  • Access blocked / app not verified — Add yourself as a test user, or publish the OAuth app.
  • No channel — Create a channel on YouTube with the same Google account.
  • Upload quota — New projects have limited daily upload quota; check Google Cloud quotas.
